# سیستم تولید برنامه هفتگی مدرسه (JavaFX)

نسخه‌ی گرافیکی پروژه: مدیر مدرسه از طریق چند تب، **معلم‌ها، دروس و کلاس‌ها را
خودش وارد می‌کند** — هیچ داده‌ای در کد اصلی (hardcode) نوشته نشده است.

## پیش‌نیاز: نصب JavaFX SDK

از جاوا ۱۱ به بعد، JavaFX دیگر جزو JDK نیست و باید جدا دانلود شود:

1. از سایت رسمی [https://gluonhq.com/products/javafx/](https://gluonhq.com/products/javafx/)
   نسخه‌ی SDK متناسب با سیستم‌عامل و نسخه‌ی JDK خودتان را دانلود کنید
   (مثلاً JavaFX 21 برای JDK 21).
2. فایل را در جایی مثل `C:\javafx-sdk-21` یا `~/javafx-sdk-21` اکسترکت کنید.
   پوشه‌ی `lib` داخل آن، همان چیزی است که در دستورات پایین لازم دارید.

## کامپایل

```bash
# ویندوز: از ; به‌جای : برای جداکننده مسیر استفاده کنید
javac --module-path /path/to/javafx-sdk-21/lib --add-modules javafx.controls \
      -d out $(find src -name "*.java")
```

در ویندوز (PowerShell):
```powershell
javac --module-path C:\javafx-sdk-21\lib --add-modules javafx.controls -d out (Get-ChildItem -Recurse -Filter *.java src | ForEach-Object { $_.FullName })
```

## اجرا

```bash
java --module-path /path/to/javafx-sdk-21/lib --add-modules javafx.controls \
     -cp out com.example.schoolschedule.MainApp
```

> اگر از IntelliJ IDEA یا Eclipse استفاده می‌کنید: پروژه را باز کنید، در
> تنظیمات VM Options همین دو فلگ (`--module-path` و `--add-modules`) را
> اضافه کنید و کلاس `MainApp` را اجرا کنید. اکثر IDEها هم پلاگین JavaFX
> دارند که این کار را ساده‌تر می‌کند.

## نحوه‌ی کار با برنامه

برنامه ۴ تب دارد که باید **به همین ترتیب** پر شوند:

1. **معلم‌ها** — نام معلم را بنویسید، روزهای در دسترسش را با چک‌باکس علامت
   بزنید، «افزودن معلم» را بزنید.
2. **دروس** — نام درس، تخصصی بودن یا نبودنش، و از لیست معلم‌ها (که در تب
   قبل ساختید) هر تعداد معلمی که می‌تواند این درس را تدریس کند انتخاب کنید.
3. **کلاس‌ها** — نام کلاس (مثلاً «الف») و پایه/رشته (مثلاً «دهم ریاضی») را
   بنویسید، بعد یکی‌یکی دروس و ساعت هفتگی هرکدام را به آن اضافه کنید و در
   آخر «ثبت کلاس» را بزنید. این تب همان چیزی است که «تعداد کلاس و مقطع
   کلاس‌ها» را مشخص می‌کند — هر بار که این کار را تکرار کنید یک کلاس جدید
   ساخته می‌شود.
4. **تولید برنامه** — تعداد زنگ در روز، چند زنگ آخر که برای دروس تخصصی
   ترجیح داده نمی‌شود، و روزهای کاری هفته را تنظیم کنید، سپس «تولید برنامه
   هفتگی» را بزنید. برای هر کلاس یک زیر-تب جداگانه با جدول برنامه‌ی آن
   کلاس نمایش داده می‌شود.

## معماری (چرا داده‌ها در کد نیستند)

| بخش | نقش |
|---|---|
| `model/*` | کلاس‌های داده‌ای خالص (Teacher، Subject، SchoolClass، ...) + `TimetableGenerator` که همان الگوریتم Backtracking نسخه‌ی قبلی است، بدون تغییر منطقی |
| `app/AppData` | یک شیء نگهدارنده‌ی سه‌تا `ObservableList` (معلم‌ها، دروس، کلاس‌ها) که بین همه‌ی تب‌ها **مشترک** است. وقتی در یک تب چیزی اضافه/حذف می‌شود، بقیه‌ی تب‌ها (مثلاً ComboBox انتخاب درس در تب کلاس‌ها) خودش آپدیت می‌شود چون همان لیست را می‌بیند |
| `ui/*` | خود فرم‌ها و جدول‌ها؛ هیچ‌کدام مقدار پیش‌فرضی برای معلم/درس/کلاس ندارند — همه از ورودی کاربر می‌آید |

قید نرم «دروس تخصصی ترجیحاً آخر وقت نباشند» دقیقاً مثل نسخه‌ی کنسولی قبلی
پیاده‌سازی شده: زنگ‌های آخر روز (تعدادشان قابل تنظیم در تب «تولید برنامه»
است) فقط وقتی امتحان می‌شوند که هیچ گزینه‌ی دیگری برای آن درس نمانده باشد.

## محدودیت این نسخه (نکته‌ی صادقانه)

این پروژه در محیط sandbox من (بدون دسترسی به اینترنت و بدون نصب JavaFX)
نوشته شده، پس نتوانستم واقعاً آن را اجرا و تست کنم. کد را خط‌به‌خط از نظر
نحوی و منطقی بازبینی کردم و مطمئنم ساختار درستی دارد، ولی لطفاً بعد از
اجرا روی سیستم خودتان، اگر خطای کامپایلی یا رفتار غیرمنتظره‌ای دیدید به من
بگویید تا فوراً اصلاحش کنم.
